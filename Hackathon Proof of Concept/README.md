## Project Summary

ClaimSignal is a grounded, human-in-the-loop AI prototype for payment-integrity claim triage. 
It combines pattern recognition, price-deviation modeling, multivariate anomaly detection, transparent risk fusion, and a constrained LLM review agent.

The POC uses synthetic/de-identified CMS claims data. It prioritizes cases for human review only and does not make clinical, fraud, payment, 
coverage, or denial decisions.
